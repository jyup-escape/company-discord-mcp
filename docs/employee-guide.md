# 社員向け：Discord MCPの登録

管理者から共有された接続URL、または`employee-kit`フォルダーを使います。Botは会社共通の1つです。社員自身がBotを作成したり、トークンを受け取ったりする必要はありません。

## 登録前に必要なもの

- 会社のDiscordサーバーに参加している自分のアカウント
- 管理者が指定している場合は社員ロール
- 普段利用するCodex、Claude Code、またはClaudeのリモートコネクター

## Windows

管理者から`npx`コマンドが共有されている場合は、ZIPの代わりにそのコマンドを実行できます。Node.js 24以上が必要です。セットアップCLIが自動取得され、Codexへの登録と接続確認を行います。認証画面が開いた場合だけDiscordで認証し、成功後にCodexを終了して開き直してください。

Codexは次の3手順です。

1. 配布ZIPを展開し、`Codexに接続.cmd`をダブルクリックします。
2. 認証画面が開いた場合だけ、自分のDiscordアカウントで認証します。
3. 「接続できました」と表示されたら、Codexアプリを終了して開き直し、新しいチャットで「会社Discordでログイン中の自分と、チャンネル一覧を確認して」と依頼します。

Codexアプリ付属の実行ファイルを自動で探すため、PATHの設定やコマンド入力は不要です。登録済みでツールを取得できる場合は再認証を省きます。`register-codex.cmd`も同じセットアップを実行します。

Claude Codeを使う場合は`register-claude-code.cmd`を実行し、Claude Code内で`/mcp`から認証します。

## Mac / Linux

ターミナルで配布フォルダーを開き、利用する方を実行します。

```sh
sh register-codex.sh
# または
sh register-claude-code.sh
```

## Claude / Claude Desktop

設定のコネクターからカスタムコネクターを追加し、配布された`connection.json`の`url`を指定します。Discordで認証してください。組織の設定によっては管理者による追加が先に必要です。

## 手動登録

配布ファイル内の`codex-config.toml`または`claude-mcp.json`を参考に、既存設定へ`company-discord`の項目を追加します。既存設定ファイル全体を置き換えないでください。Codexの認証は`codex mcp login company-discord`、Claude Codeは`/mcp`から行います。

## 初回に確認すること

1. 「Discordでログインしている自分を確認して」と依頼し、自分のアカウントであることを確認します。
2. 「Discordのチャンネル一覧を見せて」と依頼します。
3. 権限のあるチャンネルで閲覧を試します。投稿は必要な場合にだけ依頼してください。

投稿は共有Bot名義になり、本文に実行した社員のDiscord IDが付記されます。検索はチャンネルの直近最大500件が対象です。スレッド・DM・フォーラムは対象外です。

認証できない場合は、会社サーバーへの参加状態・社員ロール・管理者による利用停止状態を確認してもらってください。トークンや認証コードを社員間で共有しないでください。

セットアップに成功しても、開いたままのCodexチャットでは追加前のツール構成が使われる場合があります。Codexアプリを終了して開き直した後、新しいチャットで確認してください。

取得したメッセージは利用しているAIサービスに渡ります。会社の情報利用ルールに従って利用してください。
