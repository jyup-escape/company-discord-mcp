# Cloudflare設置の変更記録

2026-10-10（日本時間）

- 暗号化と期限管理を共通実装へ分離し、既存Node.js/SQLiteとCloudflare/Durable Objectsの両方から利用できるようにした。
- Workers用のHTTP入口を追加し、設定未完了の要求は503で拒否する。
- 同期的な原子処理を保持し、認証券の一回使用、更新トークンの再使用検出、認証状態の暗号化を維持した。
- Workers経路の要求回数を保存し、再起動による回数の消失を防いだ。
- WorkersではGatewayとRESTの定期処理を起動しない。Node.jsの起動経路は維持した。
- 公開設定、秘密情報反映用の処理、Cloudflare向け型検査、保存試験、CIの検査を追加した。
- Cloudflare認証を更新し、https://company-discord-mcp.desudesu2387.workers.dev へ公開した。
- 型の検査、34件のサーバー試験、8件の登録用試験、ビルドが成功した。Workersの実行環境で登録と再起動後の保持、同意、認証券再使用拒否、Origin検査、未認証拒否を確認した。
- Discord設定の入力前に、公開先が設定未完了の503を返すことを確認した。
- 有料プランへの変更は実施していない。無料枠と現在の利用状況を管理画面で確認する。

秘密情報はGitへ追加していない。変更の影響範囲と操作経路はdeployment-specification.mdへ記録した。

2026-10-10のCloudflare管理画面で、Workersの無料プラン（$0）が現在のプランであることを確認した。無料枠の超過による失敗とサービス側の条件変更は継続稼働の制約になる。
